CapsLock Lite 截图插件（完整版）
================================

安装
----
1. 打开 CapsLock Lite，进入左侧「插件」页，点「启用插件」并阅读风险提示。
2. 点「导入插件…」选择本文件 screenshot-pro.cs；也可以直接把文件（或整个压缩包）拖进窗口。
3. 确认框会显示文件名与 SHA-256；确认信任后，列表显示「已加载」即可使用，无需重启。

提供的动作
----------
- 截图 · 全屏截图           截取所有显示器的可见内容
- 截图 · 活动窗口截图       截取当前前台窗口
- 截图 · 自定义范围截图     冻结屏幕后拖拽框选

范围截图的操作
--------------
- 拖动：选择区域；已有选区时拖动内部可移动，拖动四角手柄可缩放
- 方向键：微调 1 像素；Shift + 方向键：10 像素
- Ctrl + A：全选；Enter / 空格 / 双击：保存；Esc 或右键：取消
- 选区外暗化、选区内为原亮度预览；选区上方显示尺寸，光标旁有 8 倍放大镜与坐标

保存
----
默认保存到「图片\CapsLockLite」，可在快捷键编辑器的「文件夹」参数里改到别的目录；
保存后自动复制文件路径。

要求
----
- CapsLock Lite 1.4.6 或更高版本。
- 插件由主程序在导入/加载时用 .NET Framework 自带的 csc.exe 编译，无需你手动编译。

更多
----
插件编写规范见 PLUGIN.md。插件拥有与主程序相同的权限；只有你显式信任该文件的 SHA-256 后才会运行。请只安装可信来源的插件。
